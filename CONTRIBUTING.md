# Contributing to Devicon

Thanks for taking the time to contribute! This project can only grow and live by your contributions.

Our contributing guidelines live in the [wiki](https://github.com/devicons/devicon/wiki). New to contributing? Start with the [Overview on Submitting Icons](https://github.com/devicons/devicon/wiki/Overview-on-Submitting-Icons).

Questions? Ask in [GitHub Discussions](https://github.com/devicons/devicon/discussions) or our [Discord community](https://github.com/devicons/devicon/wiki/Discord-community).
